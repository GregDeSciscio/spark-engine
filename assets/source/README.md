# assets/source

Source models (`.glb` / `.gltf`) before they enter the engine. Nothing in here is loaded by the app directly: `pnpm assets` runs `tools/asset-pipeline/pipeline.mjs`, which normalizes, compresses and validates every file and writes the result to `apps/benchmark/public/models/` (kickoff section 4).

```bash
pnpm assets                       # process everything
pnpm assets --only=crate          # one asset (basename without extension)
pnpm assets --dry-run --verbose   # report only, write nothing
pnpm assets --budget=enemy        # override the budget class for every file
```

Conventions the pipeline understands (kickoff section 26, ADR-008):

- `spark.type` and other `spark.*` custom properties (glTF `extras`) are preserved and listed in the report. Blender exports custom properties as extras when "Custom Properties" is ticked in the glTF exporter.
- `spark.budget` (`hero` | `enemy` | `prop`) on any node picks the triangle/texture budget used by the validator. Without it, the file name prefix (`hero-`, `enemy-`) or the `--budget=` flag decides; the default is `prop`.
- Collision meshes are named `COL_*`. They pass through untouched and are hidden by `ModelAsset.instantiate()`.
- Units are metres, Y-up. A root node carrying a bare 90° X rotation (Z-up bake) or a uniform unit scale (0.01, 0.001, 0.0254, 100, 1000) is baked into the mesh data.

The three files that ship here are generated by `node tools/asset-pipeline/make-test-assets.mjs` (deterministic; re-running rewrites identical bytes). Replace or add real assets alongside them.

## Props (`assets/source/props/`)

The showcase's street kit: CC0 models from [Poly Haven](https://polyhaven.com/models), fetched as self-contained GLBs by `tools/asset-pipeline/fetch-polyhaven.mjs` (`pnpm props:fetch`), decimated above 12k triangles toward 8k since they are street dressing seen from an over-the-shoulder camera, and listed with authors in `props/SOURCES.md`. `pnpm props:build` runs them through the pipeline into `apps/showcase/public/models/`, where the street level references them by id through `spark.type=prop` empties (see `tools/level-authoring/street.py`).
