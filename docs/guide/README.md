# Building with Spark Engine

Start here if you want to make something with the engine rather than work on the engine itself.

| | |
| --- | --- |
| [first-scene.md](first-scene.md) | Clone, run, and make your first scene in about fifteen minutes. |
| [concepts.md](concepts.md) | The engine's shape: the loop, entities, scenes, physics, animation, audio, assets, levels. One page. |
| [api-map.md](api-map.md) | Every module the engine exports, one line each, so you know what exists. |
| [recipes.md](recipes.md) | Do a specific thing: a level from Blender, a character, a weapon, a sound bank. Each points into the showcase, which already does it. |

Two more places worth knowing: `docs/decisions/` records why the engine is the way it is, and `docs/architecture/lessons-from-the-showcase.md` records every pitfall building the demo found, with the fix.

If you work with a coding assistant, `CLAUDE.md` at the repo root is written for it.
